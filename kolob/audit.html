Determinism audit

Trait + Uniqueness Audit

Runs the on-chain trait derivation against 129 demo throne hashes (the canonical test hash + a deterministic per-throne offset, matching the explorer's NODES table) and reports the result. The same derivation runs on-chain inside token.html for every minted piece.

Visual uniqueness is enforced separately by the system seed itself, every throne's full state (palette hue, planet count, types, eccentricities, orbital phases, moons, belts, comets) is built from a different seed, producing a render that lives in a multi-million-dimension state space. Hash collisions in tokenData.hash are astronomically unlikely.

Categorical trait tuples from the three hash-derived fields (Intelligence × Affinity × Dispensation) span 8 × 8 × 10 = 640 combinations. Glory is the fourth field, but it is set by the owner's tier PMP at mint/advance time, not derived from the hash, so the Monte Carlo below tests the three hash-derived fields only. Across 129 thrones, birthday-paradox math expects ~13 pairs to share a 3-field tuple. That's the same as every other Art Blocks project, individual trait values are categorical rarities, not unique IDs.
