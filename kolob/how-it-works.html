It's code, not a picture.

When you mint, the blockchain hands the artwork a unique number. That number grows a one-of-a-kind solar system, stars, planets, moons, comets, belts, live in your browser, forever, with nothing stored off-chain.

The technical bit

Deterministic generative art: tokenData.hash seeds a PRNG that builds the whole system. Same hash → same output, every time. Pure vanilla canvas, zero external dependencies, so it qualifies as fully on-chain.

Orbits are real Keplerian ellipses in integer mean-motion resonance; belts carry Kirkwood gaps; everything is particles (the "pixel-as-token" aesthetic).

How a token knows which it is

By its invocation number (mint order): invocations 0–2 are the great suns, 3–14 the core systems (all from locked seeds), and 15–143 are thrones (seeded by the token's own hash). Deterministic and permanent.

How advancing works on-chain

A throne's kingdom is an on-chain PostParam (Art Blocks PMP) set by the token owner; the artwork reads it and re-renders the new tier. PMP supports lock dates and min/max, so the "drift to Outer Darkness" deadline is enforceable on-chain. Requires Engine Flex (core v3.2.5+).

The Core 15 are authored.

Holders of the fifteen don't just own a body, they shape it. Sliders for a sun's color, flares and rotation; an archetype swap and palette for a core system; their deity's name. Sealed to their token, it becomes a true 1/1.

How authorship works

Each locked seed is a starting point. The owner's choices are stored as on-chain PostParams (Token-Owner authorized) and encoded into the render, bounded so every result still reads as a KOLOB. Authored pieces carry a ✦ badge in the collection.

Gated by token ownership (wallet signature at launch; mint-state today).

Uniqueness rules

Two safeguards make sure the fifteen Core pieces stay individually distinguishable no matter what holders do in Creator Mode.

Great Stars (3): each sun's hue is locked. Oleblish belongs to the gold band, Enish-go-on-dosh to the blue band, Kai-e-vanrash to the red band. The author can move saturation and lightness freely within that band, but the bands do not overlap. Even if all three holders push every other slider (density, length, rotation, speed, curl, flares) to identical values, the three suns are guaranteed to read as different colours.   Try Creator Mode on Oleblish ▸

Core Systems (12): archetype swap is enforced first-come, first-serve. The twelve archetypes (Ringed Dynasty, Moon Swarm, Asteroid Empire, Comet Storm, Embryo Nursery, Eccentric Chaos, Binary Heart, Resonance Cathedral, Frozen Kuiper, Hot-Jupiter Forge, Mega-Ring World, Trojan Swarms) start one per system. When a holder seals a different archetype, that choice claims the slot; the editor disables that archetype for every other holder going forward. No two sealed cores can ever share an archetype.   Try Creator Mode on Lindi ▸

Outcome: the Core 15 are a permanent, mutually-distinct ensemble. Every piece is a true 1 of 1, by hue or by archetype, forever.
